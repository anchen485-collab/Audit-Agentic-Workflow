# Day14 LangGraph 审批工作流报告

## 今日完成

- 实现 LangGraph 审批工作流。
- 将规则召回、证据采集、审批判断、人工复核任务生成和指标汇总拆分为 5 个节点。
- 定义 AuditWorkflowState，统一管理工作流状态。
- 在 10 条标准审批样例上验证 LangGraph 工作流输出结果。

## 工作流节点

- retrieve_rules：召回候选分类规则。
- collect_evidence：采集企业证据包。
- classify_cases：生成审批结论。
- create_review_tasks：创建人工复核任务。
- build_metrics：汇总审批指标。
